# أكاديمية pandas — تعلّم بالفهم لا بالحفظ

موقع تفاعلي عربي (RTL) لتعلّم **pandas** من الصفر: شرح واضح، أمثلة قابلة للتشغيل، تمارين مُصحّحة تلقائيًا، اختبارات قصيرة، وتحدٍّ نهائي — كله داخل المتصفح.

## ما الذي يميّزه؟

- **بايثون حقيقي في المتصفح** عبر [Pyodide](https://pyodide.org/) — كل مثال وتمرين يُنفَّذ فعليًا، وليس مجرد كود معروض.
- **تعلّم بالفهم** — كل درس يشرح *لماذا* تعمل الدالة، ويقارنها ببدائلها، ويطرح أسئلة فهم لا حفظ.
- **روح اللعبة** — نقاط XP تُحسب على أفضل نتيجة (إعادة المحاولة لا تكرّر المكافأة)، ستة مستويات، أوسمة، سلسلة أيام، تحدٍّ يومي، ونجوم لكل درس.
- **عربي بالكامل** — واجهة RTL، خطوط عربية مخصصة، وأكواد LTR معزولة بشكل صحيح.
- **بلا بناء ولا تثبيت** — ملفات ثابتة تعمل مباشرة في المتصفح.

## التشغيل

### الطريقة الأسرع
افتح `index.html` مباشرة في المتصفح. الموقع مصمم ليعمل عبر `file://` أيضًا، وكل المحتوى الثابت يظهر دون إنترنت.

> **ملاحظة:** أول تشغيل لأي كود بايثون يحتاج اتصالًا بالإنترنت لتحميل Pyodide (~10 ميجابايت) من CDN. بعد التحميل يبقى في ذاكرة التصفح، ويمكن استخدام زر **إعادة ضبط** في المختبر لبدء جلسة نظيفة.

### عبر خادم محلي (يُفضّل)
```bash
# من داخل مجلد المشروع
python -m http.server 8000
```
ثم افتح: <http://127.0.0.1:8000>

أي خادم ثابت آخر يعمل أيضًا (Live Server في VS Code، `npx serve`، وغيرها).

## التقدم والخصوصية

- كل شيء يعمل محليًا؛ لا يُرسل أي كود أو إجابة إلى خادم.
- التقدم محفوظ في `localStorage` تحت المفتاح `pdx-progress-v1`، وحالة اللعبة تحت `pdx-game-v1`.
- امسح بيانات الموقع من إعدادات المتصفح لبدء رحلة جديدة.

## ملاحظات للمطوّرين

- لا توجد خطوة بناء — استخدم وسوم `<script>` التقليدية (`window.PDX`).
- أضف درسًا جديدًا في `assets/js/data/lessons-*.js` وسؤاله في `quizzes-*.js`، ثم أضف تمرينه في `exercises.js`.
- احرص على تحميل `gamify.js` بعد `progress.js` و`render.js` وقبل `app.js` و`quiz.js`.
